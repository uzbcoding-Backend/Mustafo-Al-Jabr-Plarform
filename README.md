# Mustafo Al-Jabr Platform

Independent student-created educational platform inspired by Al-Jabr IFPS in Tashkent. **Not the school's official website.**

## Features
- Four subjects: English, Mathematics, Physics, and IT
- 80 original questions with a 90-minute full exam
- Result history, question review, and responsive layout
- School image gallery from supplied photos and social link to @al_jabruz

## Open the site
Open `index.html` directly in your browser. All styles, scripts and images are embedded in this HTML file.

## Publish
On GitHub open **Settings > Pages**, choose **Deploy from a branch > main > /(root)**, then save.
Expected URL: https://uzbcoding-backend.github.io/Mustafo-Al-Jabr-Plarform/

Google indexing is not automatic. Submit the live URL using Google Search Console after Pages is active.

## Accounts and security
Guest results are saved only in the current browser. Real cross-device logins and secure saved results require configuring Supabase Auth and database row-level security. **The online demo is not an official examination platform. Never share real passwords through demo pages.**

## Privacy and consent
Photos depicting students, including children, were supplied by the requester. Obtain permission from the rights holders and people photographed (or their guardians where required) before making them public. Remove images on request.
